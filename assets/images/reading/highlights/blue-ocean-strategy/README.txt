Highlight photos for: Blue Ocean Strategy

Drop the photos for this book in this folder.

Naming
  01.jpg, 02.jpg, 03.jpg ... numbered in the order you want
  them shown. .png and short .mp4 clips work too.

Sizing
  1080x1920 (9:16 portrait) fits the viewer edge to edge.
  Anything else is letterboxed rather than cropped.
  Videos: keep them short (< 30s) and web-optimised (H.264 mp4).
  They start muted so autoplay is not blocked; viewers can unmute.

A photo does nothing until it is registered. Add it to this book's
highlights array in assets/myjs/reading-data.js:

  highlights: [
    { src: "../assets/images/reading/highlights/blue-ocean-strategy/01.jpg" }
  ]

Then set highlightDate on the same book to the date you want shown
on the cover, e.g. highlightDate: "2026-03-14".

Highlights never expire. Remove a line to take a photo down.
