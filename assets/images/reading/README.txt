Drop your book cover images in this folder.

Reference them from assets/myjs/reading-data.js using paths like:
    coverImage: "../assets/images/reading/atomic-habits.jpg"

Recommended: portrait covers (e.g. 400x600). If a cover file is
missing, the card automatically shows a "No cover" placeholder.

highlights/
  One folder per book, named after that book's `slug` in
  reading-data.js. Photos dropped there appear behind the cover's
  Instagram-style gradient ring once you register them in the book's
  `highlights` array. See the README inside each folder.
