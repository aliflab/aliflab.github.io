Story media for the hero profile picture.

Naming
  YYYY-MM-DD-slug.jpg   e.g. 2026-08-01-sunrise.jpg
  YYYY-MM-DD-slug.mp4   e.g. 2026-08-02-lab.mp4

Sizing
  Images: 1080x1920 (9:16 portrait) fits the viewer edge to edge.
  Anything else is letterboxed rather than cropped.
  Videos: keep them short (< 30s) and web-optimised (H.264 mp4).
  Videos start muted so autoplay is not blocked; viewers can unmute.

After dropping a file here, register it in assets/myjs/stories-data.js
or it will not show up.
